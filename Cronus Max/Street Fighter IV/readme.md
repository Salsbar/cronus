# Street Fighter 4 Challenge Mode Trials Automation Script
## Overview
This script automates the execution of Challenge Mode trial combos in Street Fighter 4. It is designed to handle the timing and input sequences required to complete trials automatically. This collection covers all of the hard trials and most of the normal trials, making it ideal for clearing challenge combos without manual execution.

## Setup Instructions
### Positioning
1. For most scripts, position your character as close to Dan as possible, usually by cornering him.
2. If a trial indicate it begins with a jump, leave some space between your character and Dan so the jump-in has room to connect.
3. Some scripts include specific notes on when to start them and in what position. Always check for these notes before activating; if there are no notes, use the default close-range corner positioning described above.

### Starting the Script
1. Press the left stick (LS) to start a script.
2. Press the right stick (RS) to start a script.

## Script Behavior
- The script will perform the full trial combo sequence with the required input timing.
- Some scripts may take several attempts to land correctly, so be prepared to reset and retry if the combo drops.
- This collection does not include every trial. All hard trials are included, along with most of the normal trials.
- This was tested on the Games for Windows Live version but should also work on the Xbox 360 version.
- Be mindful of positioning before each attempt, since incorrect spacing (too close for a jump-in, or too far for a close-range starter) is the most common reason a script fails.
